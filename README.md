# Showcase Master Dashboard

Internal operations dashboard for AD Group's Showcase product. Deployed at `dashboard.showcase.space`.

**Stack:** Next.js 16 · TypeScript · Tailwind CSS · Express · PostgreSQL (AWS RDS)

## Quick start

```bash
cd frontend
npm install
npm run dev    # http://localhost:3000
```
